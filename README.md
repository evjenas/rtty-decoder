# RTTY декодер для Android

Расшифровка RTTY (Baudot / ITA2) через микрофон телефона.

- Водопад, настройка касанием по сигналу с автоподстройкой
- Скорость 45,45 / 50 / 75 / 100 бод, сдвиг 170 / 200 / 425 / 450 / 850 Гц
- Инверсия, порог шумоподавления, индикатор качества
- Режим «Только цифры»: выводятся только 0–9, пробел, точка и запятая
- Копирование, сохранение в «Загрузки», «Поделиться»
- Экран не гаснет во время приёма, текст сохраняется

## Установка

Откройте раздел **Releases** справа, скачайте `RttyDecoder.apk` и откройте его на телефоне
(разрешите установку из этого источника).

## Сборка

APK собирается автоматически GitHub Actions при каждом push в `main`.

Папка `web/` — та же страница для установки на свой сервер (`install-safe.sh`).
